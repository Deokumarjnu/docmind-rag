# DocMind RAG - Technical Architecture

## 🏗️ System Overview

## 🎯 Why Each Component?

| Component | Problem Solved |
|-----------|---------------|
| **Qdrant** | Fast semantic similarity search over millions of vectors |
| **Neo4j** | Multi-hop reasoning ("What is related to X?") |
| **Redis Cache** | Avoid redundant LLM calls for similar queries |
| **PostgreSQL** | Persistent conversation history for context |
| **Hybrid Retrieval** | Dense catches semantics, BM25 catches keywords |
| **Cross-encoder** | Precision improvement via pairwise scoring |
| **Self-correction** | Automatic retry when retrieval/generation fails |
| **Deep Agents** | Specialized processing for different content types |
