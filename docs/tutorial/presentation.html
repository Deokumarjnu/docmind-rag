04 / EMBEDDINGS
Teaching AI to Understand Meaning
How computers understand that "car" and "automobile" are similar
🗺️ What Are Embeddings?
Imagine a magical map where similar things are placed close together. "King" and "Queen" are close (both royalty). "King" and "Banana" are far apart.
  • Each text chunk → 3072 numbers (coordinates)
  • Similar meaning → close coordinates
  • Different meaning → far coordinates
✓ Why text-embedding-3-large?
  • 3072 dimensions = more nuance
  • State-of-the-art accuracy
  • Handles technical content well
📊 Model Comparison

⚡ The Process
# 1. Take text chunk text = "The Transformer uses attention..." # 2. Send to OpenAI embedding = openai.embed(text) # 3. Get 3072 numbers back [0.023, -0.089, 0.145, ... ] # 3072 dims # 4. Store in Qdrant qdrant.upsert(embedding, metadata)

🔄 Hybrid Retrieval
  • Dense (60%): Meaning-based (embeddings)
  • Sparse (40%): Keyword-based (BM25)
  • Why both? Dense catches synonyms, sparse catches exact terms
Reciprocal Rank Fusion:
Score = Σ 1/(k + rank)
🔁 Self-Correction Loop
  • Validate Retrieval: "Are docs relevant?"
  • If NO → retry with enhanced query
  • Validate Answer: "Is answer grounded?"
  • If NO → retry retrieval
  • Max 2 retries to prevent loops
07 / FRAMEWORKS
Why LangChain & LangGraph?
❓ Without LangChain
# Manual approach - lots of boilerplate response = openai.chat.completions.create( model="gpt-4", messages=[{"role": "user", ...}] ) # Now handle: retries, streaming, # different models, prompt templates, # output parsing, chains...
✓ With LangChain
  • Document Loaders: PDF, DOCX, HTML... (50+ formats)
  • Text Splitters: Smart chunking
  • Embeddings: Any provider, same interface
  • Vector Stores: Qdrant, Pinecone, etc.
  • Chains: Connect components
🔄 Why LangGraph for RAG?
LangChain: A → B → C (linear)
LangGraph: A → B → (if bad) → A → B → C (loops!)
  • State management across steps
  • Conditional edges (if/else)
  • Self-correction loops
  • Retry logic built-in

08 / KNOWLEDGE GRAPH
Neo4j - Understanding Relationships
❓ Vector Search Limitation
  • Great for: "Find documents about X"
  • Bad for: "What's connected to X?"
  • Can't answer: "What technologies does Transformer use?"
🕸️ What is a Knowledge Graph?
A mind map of your documents. Entities (things) connected by relationships.
[Transformer] --uses--> [Attention] [Attention] --has_type--> [Self-Attention] [BERT] --based_on--> [Transformer] [GPT] --based_on--> [Transformer]
🏆 Why Neo4j?
Graph DBProsCons
Neo4j ✓Mature, Cypher, visualizationResource heavy
NeptuneManaged, scalableAWS lock-in
ArangoDBMulti-modelLess graph-focused
💡 When It's Useful
  • Multi-hop: "What do BERT and GPT have in common?"
  • Relationships: "What uses Attention?"
  • Exploration: "Show everything related to X"
